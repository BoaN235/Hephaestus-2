# Hephaestus-2
I am redesigning my 3d printer from infill. It will have a kinematic bed along with many improvements in the belt and head systems

## Criteria and Constraints:
1. 235x235
2. CoreXY movement system
3. Tension control in the belt
4. Compact small footprint
5. Enclosed
6. Kinematic Bed (The bed will tilt)
