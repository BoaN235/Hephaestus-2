# Firmware

This project uses Klipper and has a config file that should be able to be loaded into Klipper and work.

If you don't know what Klipper is it's a software that communicates between a Micro-Controller and a General Purpose Computer to tell the 3D Printer what to do. This is allows for greater precision by telling the Computer to calculate variables and commands while the Micro Controller handles executing commands. 

Check it out on [github](https://github.com/Klipper3d/klipper/)
